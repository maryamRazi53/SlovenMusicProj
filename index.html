🎧 Project Music

Build a music player app with the iTunes Search API.

    Open the starter project

    Goal: the starter files are open in Visual Studio Code and the page shows in your browser.
    1. Unzip the file you received from your teacher.
    2. In VS Code choose File ▸ Open Folder and select the unzipped folder.
    3. Right-click index.html and choose Open with Live Server.

    You will edit index.html and js/script.js. The CSS is already done. You need an internet connection, because the songs come from the web.

    Meet the API

    Goal: you have seen the song data in your browser. No key and no account needed.

    An API is a web address that returns data instead of a web page. Apple’s iTunes Search API is free and needs no key. Paste this address into a new browser tab:

    • media=music&entity=song asks for songs only.
    • limit=5 asks for 5 results.
    • term=pop is the search word.

    Look at one result. These four fields are the ones we need:

    • trackName: the song title
    • artistName: the artist
    • artworkUrl100: the cover image (100 × 100 pixels)
    • previewUrl: an audio file with a 30-second preview of the song
